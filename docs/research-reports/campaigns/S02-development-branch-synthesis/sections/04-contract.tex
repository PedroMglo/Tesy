\section{Contrato experimental}
Branch é proveniência de desenvolvimento, não autoridade para uma métrica. Cada afirmação experimental nesta síntese aponta para o documento de resultado/preflight preservado e congelado em \texttt{evidence-lock.json}. A data e o SHA de HEAD identificam a fotografia das refs; a identidade de execução continua a ser a indicada dentro de cada relatório-fonte.

Não foram reconstruídos raws nem repetidas campanhas. Médias ponderadas, observações únicas, logits de checkpoints e regras de admissão mantêm seus próprios escopos. Igualdade de logits num caso não prova equivalência universal; falha numérica não demonstra impossibilidade geral; preflight não é resultado de inferência. Nenhum guard histórico é reclassificado como limite de hardware.
