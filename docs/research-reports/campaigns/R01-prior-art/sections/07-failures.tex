\section{Hipóteses de novidade eliminadas}
Não reclamar como novidade ampla: expert offloading/prefetch/cache, CPU experts, CPU/GPU hybrid, storage tier, predictor só para transfer, Belady ou Roofline/Amdahl.

Um comparador pode ser relevante sem satisfazer o mesmo contrato. Técnicas que alteram routing, fazem expert deferral/drop, comprimem adicionalmente pesos/KV ou aceitam perda de accuracy devem ser comparadas como sistemas relacionados, não apresentadas como equivalentes exactos ao target Tesy.
