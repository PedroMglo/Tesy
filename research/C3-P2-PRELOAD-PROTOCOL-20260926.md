# C3 P2 prospective next-wave preload test

Frozen at lab base `5f47c6d` before any P2 model run. This is intervention **1/4** if executed. Hypothesis: the pinned backend's preload of the next wave of the **current routed microbatch** can overlap read/upload with current-wave compute and reduce the measured prefill stall. It does not predict future token routing. Primary measure is untraced prefill wall time at 496 and 1522 frozen official-tokenizer IDs; prospectively require at least 25% reduction at **both** lengths for the engineering goal, with decode at least 3 tok/s and no correctness/resource regression. No candidate is promoted from one screening run. A smaller change can be reported but not relabelled as the goal.

Only change from the P1/R3 GPU8, 32 expert slots, context4096, batch256/ubatch32, CPU8/I/O4, O_DIRECT, no-repack/op-offload profile: remove `LLAMA_MOE_STREAM_NO_PRELOAD` **entirely** from the environment. Value `0` would still disable it in the pinned source. The backend source/binary and GGUF stay pinned. All runs have fresh 18 GiB cgroup, swap.max0, RSS17 GiB, GPU7000 MiB, MemAvailable6 GiB, CPU/GPU/NVMe 95/80/70 C, required ~1 s telemetry, and no model process overlap. Page cache is uncontrolled; there is no global cache manipulation.

First qualification: two new callback captures on the frozen `results/c2-target-numeric-v1.ids` (`log_medium` and `spec_pressure`) at all 36 layers and seven positions each. Direct active-slot bytes at CPU0/GPU35 must match canonical GGUF. Compare logical router logits/top-k/weights, pre-FFN input and FFN output bitwise against the already independently referenced R2 no-preload captures, with matching shapes and complete rows. Compare seven full logits vectors per case. Physical slot IDs may differ and are not used as logical IDs. The transitive reference is valid only if the compared activation/router/FFN tensors are bitwise equal; otherwise perform new independent layer replay before interpreting the mismatch. A failed capture or comparison ends this candidate qualification.

If numeric qualification passes, screen once on the exact P1 `results/c3-p1-latency-ids01.tsv` with `tools/c3_prefill_probe` in fixed short→medium→long order, KV cleared between cases, expert cache retained. Compare three complete final prompt logit vectors bitwise with P1 control, require finite and complete counters, and report raw per-case wall, preload issued/ready, misses, wait, resource peaks/events. Timing must be uninstrumented by the I/O interposer. A capture callback is never a timing arm.

Only if screening shows a plausible benefit and no regression, run three **new**, alternating control/candidate pairs on the same inputs and resources, then a frozen 20-request sustained target server protocol with decode≥3 tok/s and resource/correctness gates. Without these, status is SHORT_ONLY/NO_PROMOTION and C2's no-preload sustained profile remains default. A/B dispersion and order are reported; runs are not trimmed for EOS or slow periods. Failure/timeout keeps its identity and is not resumed under the same run ID.

Source identities, exact commands, manifests, samples and local raw roots are retained with no-replace. Compact reports only go into Git. No remote publication under C3 authority.
