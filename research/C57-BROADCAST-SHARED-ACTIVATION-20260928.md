# C57 shared activation broadcast discriminant

- Objective: test whether C48's parked-pair conversion skip suppresses a shared activation used by another active pair.
- Base: C48 backend `0bc5c75c273abaa34e51d0af932a96969665c3a3`, isolated at `/tmp/tesy-c48-backend-20260928`. C48's `FAIL_SAME_PROFILE_FIDELITY` remains unchanged.
- Evidence class: SOURCE_AUDITED and REPRODUZIDO_MODEL_FREE only. No 120B inference, full-layer reference, or timing from C57.
- Counterexample: `src1.ne[1]=1`, four IDs for a token `[-1,1,-1,-1]`. The conversion loop checks the first parked ID and leaves the one shared activation row unconverted; the MMID consumer selects that row using `id % ne11`. On the old library, MXFP4 and F16 active outputs differ from a control with the parked first ID replaced by an active ID; poisoned scratch produces an active NaN. F32 does not require conversion and passes.
- Local repair: convert every activation row, while continuing to skip parked MMIDs and writing their temporary output as +0. Backend source commit `aac3bbde35575044d290798a120cde038f85b670`; patch `research/patches/C57-broadcast-shared-activation-model-free.patch`. The old backend and build remain untouched.
- Tests: the same four-thread real GGML graph was run against old and repaired CPU libraries with MXFP4, F16 and F32; `ne11=1` and nonbroadcast `ne11=4`; first parked, first active, all parked and all active patterns; two tokens and 0x00/0x7f scratch poison. Old library reproduced the predicted mismatch, repaired library passed bitwise active controls and +0 parked outputs. The repaired build used GCC 15.3.1 with `TESY_C47_CPU_SKIP_PARKED`; a preliminary configuration without that define crashed on negative ID and was discarded as a test-build error, not a model result.
- Alternatives and limits: this mechanism explains a concrete model-free bug but does not establish it as the only C48 cause. The test does not yet cover full gate/up/down, biases, mask/reduction, unusual views or the 36-layer boundary. CUDA and attention/KV remain outside this operator test.
- Decision: keep C57 SOURCE_ONLY / MODEL_FREE_PASS. Before full-model timing, run targeted boundary captures and resident reference under a new physical identity; if fidelity fails, preserve that failure and diagnose separately.
