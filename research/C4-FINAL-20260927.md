## What was learned

Q0 model-free delayed-work and missing-output tests passed; 33 existing model-free tests passed. The physical C4 short smoke matched the C3 short logits bitwise. The measured **final** synchronization tail was ~2.6–3.0 ms in C4 short/long controls; deferred work may have waited inside earlier decode calls, so this is not a retroactive estimate of the C3 timing error. C3 prefill A/B medians 17.5149%/18.2400% remain historical dispatch-scope summaries; the C3 sustained server used a different timing path. C4 did not run a new matched three-pair preload A/B.

Two OFF and one ON long-first control used the same 1522 IDs and four frozen teacher-forced continuation IDs. Their five full logits vectors were bitwise equal with OFF preloads 0 and ON preloads 19,293. Completed prefill times 442.112886/446.287775/367.557353 s were collected for numerical diagnostics, not accepted as matched causal performance confirmation. C2/C3 historical server text had no sufficient exact original IDs or sampler state to locate the older divergence. The contemporary fixed-ID result cannot erase it.

P0 found real repeated load/wait activity and static parking work, but did not establish which fraction of critical prefill time is avoidable. C3's 1522-ID OFF trace had 432.962 GB of application `pread` returns and 69.44% empty wave callbacks. On a C4 short OFF Nsight diagnostic, 4048 GPU kernel events summed to 0.191 s and 3017 CUDA copy events to 0.800 s; sums overlap. A separate loss-free `perf` sample attributed 81.81% of user CPU cycles to MXFP4 vector dot but did not distinguish parked MoE pairs from useful or dense operations. Static ten-wave counts are not ten equivalent executed GEMMs or a 10× opportunity. A 25% total saving from eliminating 90% of a serial component would require that component to occupy at least 27.8% of critical time before overhead; this fraction was not measured. Wave-capacity and pair-compaction patches were therefore **NOT_RUN**.

The ub64 canonical layer replay passed on n64/64/30 prefill and n1 decode captured states, while the fixed-external-batch short full model diverged. This narrows the next numerical investigation to shape-dependent full-model execution; it does not identify the first changed internal operator or prove a fault in the streamed expert boundary. No tolerance, model, top-k, weights, quantization, context, sampler or output cap was changed to accept the candidate.
