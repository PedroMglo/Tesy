# C3 target negative and delayed-read diagnostics

Frozen before these target runs. Binary SHA-256 `0d06c7b204493af115fca159ffd84953af542e11bbbb4b763d02c8ecd7f17646`; pinned model/backend, `log_medium` IDs, GPU8/32 slots, ubatch32, direct I/O, no preload, 18 GiB cgroup/zero swap and thermal/watchdog thresholds as in the broad capture. Every run has a fresh ID and raw root. A negative test PASS means the deliberately faulty diagnostic is rejected with the expected marker and reason, with zero runtime swap/OOM; the model invocation itself remains FAIL and is never promoted as a successful output.

`wrong_id`, `stale_byte`, `bias_index` are test-only mutations in the separate boundary observer, never in model weights or backend. At the first active consumer pair, respectively: perturb the observed logical ID before residency check; flip one observed encoded matrix byte before comparison; use the physical slot as the F32 bias index while the oracle expects the logical expert. Expected: each is caught at the boundary and the process fails before a complete capture. This tests the observer's sensitivity, not an actual runtime defect.

Read faults reuse C2's locally tested `libc2_fault_pread.so`, with `TESY_C2_FAULT_DEFER=1`; the capture tool calls its arm function only after model/context load. For `eio`, `eof` and one 4096-byte short read, expected: exactly one injected marker, the backend's expert-load error and process failure without completed output. `delay` pauses one expert read by about 200 ms and should complete with exact consumer bytes, slot generations and two full logits rows bitwise equal to the callback-OFF control. The interposer never writes weights. An upload fault and forced stale queued publication remain NOT_RUN unless a safe hook exists in this pin.

An omitted-wave fixture is constructed from local captured `ffn_moe_down_biased`, wave mask and routing weight arrays by removing one real wave contribution from the saved FFN output in a disposable symlink copy; the canonical layer replay must reject it. A wrong-ID fixture alters one captured selected logical ID and the replay must reject it. These are model-free replays of real target captures, not target failures. No tolerance is chosen from their errors. All fixture roots are no-replace and outputs include hashes. The original raw captures remain byte-identical.
