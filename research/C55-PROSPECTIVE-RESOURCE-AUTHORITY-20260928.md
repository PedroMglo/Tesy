# C55 prospective resource authority

- Objective: make a single versioned resource authority flow from the inventory through launch, monitor, and receipt for new campaigns. Historical protocols retain their frozen rules.
- Base: `fbcb84d0e4e21403c61893b329aa6a6102ca3b55`; local proposal `1cd1a6dc610abaa237a42a57b60881472719b6c1` was cherry-picked as `b456d2a53dae0a51f1b191e14aa55fef09ae7080` and corrected here. The proposal alone had no 120B validation.
- Evidence class: SOURCE_AUDITED and REPRODUZIDO_MODEL_FREE. No new 120B model inference is claimed in this note.
- Alternative: retain E18/CPU95/GPU80/NVMe70 hardcodes. That alternative made a new cgroup cap and current device telemetry disagree with the frozen protocol.
- Decision: a new `resources` v2 section embeds the inventory snapshot and hash, derives one cap and stop policy, and rejects contradictory legacy fields. The start gate rechecks cap plus host reserve, sensor identity, thermals, AC/profile and PSI before launch. Runtime monitoring and receipt validation use the same frozen section. C35 historical preflight remains historical; C55 is the prospective path.
- Physical inventory: HX370, RTX 4060 Laptop UUID `GPU-83d90c55-1d92-75da-fc30-7771a85f2521`, NVMe0 Composite, AC/performance. The 60 s C55b baseline admitted at most 19 GiB under the reserve formula; E18 was exercised in a real user scope with zero workload swap. The GPU T.Limit values on this driver are relative: max operating 87 C, slowdown 89 C, shutdown 99 C; this protocol stops at 89 C. NVMe Composite critical 89.85 C gives 87.85 C prospective stop. CPU 95 C is warning, 100 C stop for this confirmed HX370.
- Tests: the complete `tools/test_*.py` model-free suite passed 116 tests, including a spawned child, monitor, raw receipt and invalid CPU/cgroup/GPU/PSI/library controls. Real small scope and monitor smoke passed. C55 first inventory attempt failed before model because root cgroup `memory.max` is absent; C55b fixed this and the original failure stays recorded.
- Limitations: these are policy and model-free checks, not proof under 120B load. Software sampling cannot rule out excursions between samples. The snapshot is a point-in-time admission; it must be reacquired before a physical family. Unknown GPU temperature thresholds use a labelled local 80 C fallback; no device-limit claim follows from that fallback.
- Next gate: freeze a short physical policy canary with the unchanged session backend and a fresh 60 s inventory, then validate its mapped libraries, resources and receipt before other model units. The C48 numeric failure is separate.
