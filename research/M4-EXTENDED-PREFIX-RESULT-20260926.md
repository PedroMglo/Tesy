# M4 extended-prefix diagnostic: resource stop before logits

Objective, fixed input, limits and exact bitwise metric: `research/M4-EXTENDED-PREFIX-PREFLIGHT-20260926.md`, base lab commit `f8be501356633c337fee8b9737f7606d4a82817c`, freeze commit `7611d23`. Evidence class is a measured resource failure of the diagnostic reference, not a numerical failure and not a target performance result. The first run `probe120b-fullprefix-ref01` used the isolated reference backend commit `e5230b922aa4b4b410b2aaa38bd291fe9bd40bcd`, the already verified 120B MXFP4 GGUF, CPU0, mmap without eager prefetch, the entire fixed Harmony prefix, context4096/microbatch32, 18 GiB cgroup and zero swap. The JSON manifest records full command, binary hash, limit events and samples; raw stderr/samples are retained locally outside Git.

The watchdog stopped the process after 34.415 s with `stop_reason=CGROUP_LIMIT_HIT`, return code -15. Sampled cgroup memory reached 19,327,057,920 bytes against `memory.max=19,327,352,832` bytes (18 GiB); `memory.events max` rose by 2130. Sampled `memory.stat.file` reached 18,697,699,328 bytes while process RSS reached 11,944,935,424 bytes. There was zero swap and zero OOM. The file charge is consistent with reference mmap page residency driving this limit, but it is not a per-page causal trace. No complete logit row or token-count line was produced. The comparison metric is therefore **NOT_RUN**, not PASS or numerical FAIL.

The planned streamed counterpart `probe120b-fullprefix-stream24-01` was **NOT_RUN** because the frozen campaign's resource-stop rule ended the campaign. No cgroup threshold, prefix, workload, backend or artefact was changed after the failure. The earlier four-token bitwise equality remains valid only for its declared coverage. This resource stop does not prove the target cannot be referenced on another host or with another prospectively justified method; it limits this bounded same-host comparison. Alternative future work could use a new isolated diagnostic loader that releases mapped pages after safe consumption, but that source change would require its own correctness proof and is not justified solely to manufacture a passing comparison. No optimization was retained or reverted.
