# C106 bounded RAM L2 fixed-trace screen

- **Objective/base:** Screen whether a small encoded RAM L2 could avoid enough expert demand I/O to justify a prototype. Base C105 result `a31b40c`, trace SHA `bb3ae9352749283f76ce12b65ea76801916396f87849d609169215fefdf4e40d`. Evidence class INFERIDO from a measured target trace; no new model run.
- **Alternatives/policies:** Simulated global 1/2/3 GiB LRU retaining each completed load versus inserting only an expert evicted from a primary slot. Each expert is 13,219,200 B. The latter assumes a free encoded CPU/GPU-to-RAM copy and is optimistic. Router sequence and primary cache behavior remain fixed; state=0 `DEMAND` counts an absent-primary expert, state=1/2 are resident/in-flight.
- **Observed simulation:** 2500 absent-primary demands on the 189+32 numeric workload. Load-insert LRU saved 0%, 0.04%, 0.08% of demanded logical bytes for 1/2/3 GiB. Optimistic eviction-insert LRU saved 8.84%, 11.40%, 13.36%. Its 3 GiB decode-only CPU/GPU savings were 16.48%/3.12% of absent demands. All miss the prospective >=20% target-workload byte gate. Trace wait-interval union was 25.789 s prefill and 8.654 s decode, diagnostic only, not removable critical-path time.
- **Capacity/decision:** C105 cgroup peak plus 3 GiB L2 leaves only 82,640,896 B before the E18 preventive stop, excluding copies/staging; 3 GiB is not conservatively admitted. `NO_GO_L2_189_PLUS_32_FIXED_TRACE`: do not build L2 for this workload. This does not reject warm exact-prefix 153-ID sessions or a different memory envelope. C100 `NO_GO_CONFIRM` and older FAILs remain; M3 partial, M4 unmet, default unchanged.
- **Tests/limits:** `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tools python3 -m unittest tools.test_c106_l2_trace_screen` passed 4 directed tests; `tools/c106_l2_trace_screen.py` hash-checks and validates C105 raw before simulation. The original uncommitted decision draft contained an arithmetic wording error and is retained as `decision-draft-arithmetic-error.json`; `decision.json` gives the corrected 82.6 MB margin. Logical bytes are neither exclusive physical NVMe traffic nor saved elapsed time. A new 512-prefix/153-new-ID trace is the next discriminant if warm-session reuse remains the main L2 rationale; it needs event-cap feasibility, a same-profile bridge and fresh resource admission before model use.
