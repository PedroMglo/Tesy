# C2-A gate repair and historical reanalysis

Objective: make future promotion fail closed before any new model timing, then re-read campaign 1 raw files without changing their gates, reports or run IDs. Base lab commit `c67529e`; C2 gate implementation commit `c15ab5c`. Evidence classes: REPRODUZIDO_MODEL_FREE for 18 mutation tests; reaudited legacy local files for the historical calculations; no new target model measurement in this phase. Alternatives: leave the old analyzer as the gate (rejected after reproducing false approval paths), or replace the experiment harness wholesale (unnecessary at this stage).

Three concrete old defects were found in source and counterexamples: `analyze_task_run.py` computed API/backend `counts_agree` but omitted it from `m5`; timing extraction used `zip()` without an explicit one-to-one gate; empty/missing telemetry did not veto M5. `compare_logits.py` returned exit code 0 for unequal rows. The new `tools/c2_gate.py` uses a frozen external `c2-protocol-v1` and exact `c2-run-v1` keys, strict duplicate/nonfinite JSON handling, unique request/backend IDs, matching API/backend prompt+completion counts, finite positive timings, complete 1-second telemetry with <=3 s gap and <=2 s process boundaries, fixed PID, measured cgroup peak/guards, swap/events/sensors and unrounded duration/rate checks. Unexpected keys, bool-as-number, missing data and output overwrite fail. `compare_logits.py --require-bitwise` now exits 1 for unequal complete rows. Eighteen model-free tests passed, including all listed defect classes. The old analyzers were made non-overwriting and their legacy gate now includes count/telemetry checks; they remain named legacy readers, not the new C2 gate.

Historical raw stdout/stderr/samples existed locally. The 24-slot M5 target run was recalculated at 2294 tokens / 839.31209 s = 2.733190701 tok/s, ten unique expected requests, matching API/backend counts, continuous legacy sample coverage (first at 2.073 s, last 0.766 s before process end, maximum gap 1.436 s), and zero recorded resource violations. It still passes its **original** corrected frozen secondary criterion; it does **not** qualify under the new `c2-run-v1` because old samples lack per-sample PID and kernel `memory.peak`. The stock 20B ten-request run was likewise re-read and its original M5 target status remains false. The six 24/32-slot CLI runs reprocessed from raw stdout/stderr/samples reproduce 2.567664 and 3.269265 mean aggregate decode tok/s with identical response hashes, no recorded resource event and legacy sample coverage. Sustained32 remains NOT_RUN.

The saved M6 automatic graders were rerun on saved synthetic responses. Inside the current tool sandbox, `bubblewrap` could not create a NETLINK_ROUTE socket and produced false code/SQL FAILs; those local diagnostic reports remain separate and are not model scores. A host-side isolated rerun of the same fixed validator matched all ten prior automatic statuses for each model. The saved human criterion judgments remain 8/10 for both and were checked for IDs/count consistency, not independently readjudicated. Source hashes, analyzer commit and per-run reanalysis statuses are in `results/c2-historical-reaudit-index.json`. Those hashes attest to local files now, not a cryptographic snapshot taken at the old run time. The historical `results/campaign-summary.json` remains byte-for-byte intact, SHA-256 `ce8a4da41ccc7a2168f17f31393b71404397f69e92ebe233bd0a8e8aeef188a4`.

Decision: **C2_A_GATES_VALIDATED** for model-free synthetic tests and the current legacy reanalysis. The historical M5/short A/B claims retain only their original declared coverage. New timing promotion requires a fresh `c2-run-v1` producer and a new model smoke through the strict gate; this is NOT_RUN here. Limitations: old raw logs cannot provide PID-at-sample or memory.peak retroactively, and host-side automatic grading does not itself recheck the four manually judged cases. Next discriminating gate: freeze C2-E fixtures before new responses, extend target numeric probe and execute a small new-model harness smoke with complete telemetry.
