# A política de proposta do servidor ajuda os dois turnos históricos?

Pré-registo de 26 de novembro de 2026. O ensaio de largura três já foi favorável nos casos artificiais do backend C269. O T2 nominal de C281 tinha onze propostas no replay do helper nativo. Antes de outra conversa, testar a política pública de especulação usada pelo servidor nos dois turnos, incluindo as rejeições do primeiro turno e o limite de geração. Este diagnóstico pode localizar onde o risco se concentra e evita atribuir benefícios a blocos que o servidor nunca envia.

- Selar os IDs reais de entrada e os 78/47 IDs amostrados com EOG da parte 29. Confirmar o hash dos dois vetores de entrada e dos dois de saída sem publicar conteúdo privado. Usar o prompt de cada turno já renderizado e tokenizado pelo target, contexto 8192, uma sequência, cap 256, N=2/M=2 e sem draft auxiliar.
- Compilar um cliente pequeno ligado à mesma biblioteca common do servidor de produto. Passar as flags pelo parser da CLI para LLAMA_EXAMPLE_SERVER, confirmar a configuração e a reserva derivada 1/3. Reproduzir begin, draft, commit e accept da sequência. A proposta vê apenas o prefixo confirmado e a última amostra. A referência dá o ID do target apenas na posição consultada. Comparar cada vetor proposto, profundidade aceita, token emitido e estado de histórico com o helper de referência e o replay independente. Distinguir os dados de target após EOG, a limitação do contexto e o limite do pedido.
- Conservar T1 e T2 separados, proporção de rejeições 0/1/2, chamadas AR, blocos de largura 1/2/3 e o maior custo B3 médio compatível com não piorar o decode de cada turno sob custo AR uniforme. Numa sessão futura, medir esse custo, o prefill e o primeiro conteúdo final no servidor. Os segundos de uma fixture de 189 posições não são transportáveis para os 2 197 IDs do T2.
- Uma divergência invalida a previsão por helper nesse corte. Uma largura de verificação ainda sem paridade identifica um novo pré-requisito. Dois replays independentes com o mesmo resultado só autorizam o ensaio de integração no modelo. Até uma compilação em 1 GiB, dois replays, três minutos, zero modelos, zero GPU para execução e zero rede. Preservar os FAIL e todos os vetores privados localmente.
