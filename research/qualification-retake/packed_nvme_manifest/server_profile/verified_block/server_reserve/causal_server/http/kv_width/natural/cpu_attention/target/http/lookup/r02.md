# Repetição após falha na aplicação do patch

R01 recompilou o objeto e a biblioteca comum do controlo com os mesmos SHA-256 da instalação. O primeiro hunk do patch experimental tinha uma contagem de linhas incorreta. O utilitário terminou com código 1 antes de compilar o candidato ou de iniciar o dispatcher. A saída, rejeição e recibo FAIL foram preservados. R02 usa um diff regenerado contra a mesma fonte pinada e validado por `git apply --check` e por `patch --dry-run --fuzz=0`. A condição C++, os casos e os critérios do protocolo são os mesmos.
