Os três processos passaram a sondagem do servidor, os 2 043 IDs iniciais nos nove cortes externos e os 20 IDs greedy até à primeira proposta. Os dois logits completos de controlo, o hash do KV de entrada de 80 759 344 B e os pools coincidiram. ON construiu a atenção de L25 com 2 304 células. Todas as 78 732 linhas de K ou V da passagem anterior conservaram a igualdade com P no estado final. As seis linhas novas da camada 0 também coincidiram. Nas posições 2 062–2 064 da camada 1 divergiram 2 888 das 3 072 palavras F16. O conjunto das camadas 1–35 contém as 105 989 diferenças finitas. A memória final tem 80 869 972 B por braço. O pool de saída ON também divergiu. A redução observada de uma carga lógica de 13 219 200 B ocorreu numa trajetória numericamente rejeitada.

A localização limita a primeira causa possível ao percurso que produz K/V na camada 1, incluindo as operações da camada 0. As capturas não individualizam Q, as máscaras, a saída de atenção ou o FFN de 0. O código CPU escolhe uma redução repartida por blocos de KV em certas consultas de uma posição a partir de 512 células. A verificação de três posições segue outro ramo nesse operador. É uma hipótese que pode ser testada em CPU antes de outro forward com modelo. O melhor caso do pack ainda tem um défice nominal de 8,313 s e 0,639 tok/s.
