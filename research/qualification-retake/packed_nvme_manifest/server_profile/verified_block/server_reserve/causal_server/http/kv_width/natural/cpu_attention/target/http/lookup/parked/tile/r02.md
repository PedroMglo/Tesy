# Execução da referência independente

O build R01 passou. O arquivo privado guarda o conteúdo de STOCK sem permissão de execução. A família de exatidão R01 parou no primeiro lançamento com EACCES, antes de executar o processo ou obter resultados numéricos. Os dois ficheiros de saída desse braço ficaram vazios e o timing R01 ficou NOT_RUN.

No novo build copiar STOCK para o diretório privado do ensaio, dar permissão de execução apenas à cópia e exigir o mesmo SHA do ELF confirmado na parte 122 antes e depois. As permissões e os bytes do arquivo ficam preservados. Aplicam-se o protocolo, a ordem, o orçamento numérico e as comparações anteriores. A compilação de diagnóstico e os seus custos ficam identificados separadamente.
