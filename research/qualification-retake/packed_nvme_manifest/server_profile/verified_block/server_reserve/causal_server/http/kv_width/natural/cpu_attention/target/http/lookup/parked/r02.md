# Diagnóstico do controlo não finito

R01 parou na fixture de NaN antes de construir o grafo ou avaliar um tensor. A chamada C++ não qualificada com um único valor entre chavetas também admitia a função C `finite(double)`. O controlo verificou que nenhuma exceção foi lançada e encerrou. O ficheiro de saída do grafo tem zero bytes. Conservar esta falha e o primeiro ELF.

R02 dá ao verificador de vetor um nome próprio e passa um vetor explicitamente construído ao teste de NaN. O [protocolo](protocol.md), o backend, os dados, os critérios e os limites de recurso aplicam-se às novas identidades de build e execução. Esta alteração corrige a ligação do controlo de falha à função que a referência e o candidato usam nos vetores completos.
