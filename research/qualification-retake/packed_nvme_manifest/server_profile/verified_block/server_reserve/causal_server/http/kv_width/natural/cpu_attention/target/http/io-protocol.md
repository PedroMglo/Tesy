# Quanto serviço de armazenamento cabe antes do primeiro final?

A pergunta é se o volume de serviço observado no controlo serial OFF pode caber nesses prazos e, se não couber, quantos bytes têm de sair da janela. Avaliar ainda a hipótese de atingir exatamente 6 tok/s no trajeto medido e creditar toda a redução de decode antes do primeiro final.
