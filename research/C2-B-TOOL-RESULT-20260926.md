# C2-B probe/tool gate before target reference

Objective: verify multi-row teacher forcing, KV positions, output size and fail-closed comparison on a local surrogate before a 120B reference. Base C2 protocol commit `b8f5123`, original streamed backend SHA `1248fd8fa8cfebaece5ea992e4d951c1e18bb9d5`, isolated no-prefetch reference SHA `e5230b922aa4b4b410b2aaa38bd291fe9bd40bcd`. Both probe binaries compiled with GCC15.3.1 against their own pinned build libraries; per-run manifests contain their SHA-256 identities. No backend weights or Transformer math changed.

Model-free numeric tests passed: a three-row synthetic equality and inequality, omitted row detection, and the required nonzero exit for a wrong bitwise comparison. The official target tokenizer produced the shared fixed ID file with 110+26, 189+43 and 414+49 case lengths. Target GGUF SHA-256 matched the lock in a read-only O_DIRECT checksum run. Three model-free monitor smokes tested the new cgroup `memory.peak`, events.local, PSI and PID samples. The final smoke had first sample 0.066 s after child launch, end gap 1.000 s, maximum intersample gap 1.080 s; the first two had initial sensor-query startup around 1.95 s and remain recorded. Sensor preflight now occurs before the timed child launch. Memory and thermal watchdog thresholds remain 18 GiB/zero swap, RSS17 GiB for production, GPU7000 MiB, MemAvailable6 GiB, CPU95 C, GPU80 C and NVMe70 C.

Real 20B tool smoke `c2-probe20b-stream-short01` completed `quant_short`: 110 prompt +26 continuation IDs, 30 full final-logit rows, 201,088 float32 elements per row; direct expert FDs, 864 misses of which 688 cold, zero swap/OOM/max, peak cgroup 10,472,841,216 bytes and GPU 116 MiB. CPU Tctl reached 90.5 C, below the frozen 95 C guard. Independent plain `c2-probe20b-plain-short01` completed the same IDs and row map under the same 18 GiB/zero-swap envelope, with zero stop events. `results/c2-probe20b-plain-stream-short01-compare.json` reports **30/30 complete rows bitwise equal**, no nonfinite values, not just a final vector. These rows span prompt chunk boundaries and incremental continuation states. This is measured surrogate tool/CPU-path validation, not target correctness or production GPU8 parity.

Decision: use the same unmodified probe and token ID file for the target reference. Alternative of trusting only generated text rejected because it would miss incorrect logits before token divergence. The source/binary identities and raw `.f32` rows remain available locally; only compact manifests/comparison are committed. Next gate: target plain CPU `REFERENCE_RECLAIM_ALLOWED` under 18 GiB and zero swap, followed by original streamed CPU comparison if the reference completes. Target C2-B result NOT_RUN at this checkpoint.
