# C3 R2 broad boundary capture protocol

Frozen before any broad model run. Base `9e9ea16`, target and backend pins from `C3-PROTOCOL-20260926.md`. Input IDs are the existing `results/c2-target-numeric-v1.ids` (SHA-256 `8fb3aff447febaeaa5a8bdd0c485fd20d51d39fb6ac3e6ba4849eb4a664dbc23`), cases `log_medium` (189 prompt +43 fixed continuation IDs) and `spec_pressure` (414+49); lengths must be checked by the runner. Each case is a fresh model process and scope; processes run sequentially. This controls the inputs but does not simulate multi-request cache history. No timing claim from callback-enabled runs.

GPU8/32 slots, context4096, batch256/ubatch32, threads8, I/O4, O_DIRECT, no preload/repack/op offload. For each case capture all 36 layers at prefill chunks starting 0, 128 and the last 32-ID-aligned prompt chunk (160 or 384), plus incremental continuation positions 0, 1, 7 and 31. Each selected prefill invocation contains its full native microbatch, including its actual last-layer shape. Intermediate chunks and decode positions needed to establish KV are evaluated with capture off. `llama_decode` receives every prefix ID in order; no generation chooses new tokens. Each captured phase has full `attn_post_norm`, router logits/top-k/weights, physical slot/wave IDs and mask, and FFN output. Full final logits at captured continuation positions are saved for OFF/ON checks; their absence does not invalidate a boundary-only row but limits full-model claims. Raw cap 256 MiB per case; it is not a memory budget. The capture copies tensor bytes at callback completion; no pointers persist to later graph invocations.

Consumer bytes are checked against independent GGUF `pread` slices for layers 0 and 35 at `prefill0` and `decode0` in each case, with active wave masking. Other layers' bytes receive canonical reference reconstruction and output comparison, but no direct slot-byte witness unless later added. Every layer reference loads exactly one canonical layer (all 128 experts and biases plus router) from GGUF independently of streaming remap and frees it before the next layer. CPU layers 0–27 replay on CPU; GPU layers 28–35 replay on GPU, as verified from actual backend placement/source. All existing phases for a layer are replayed before its weights are freed.

Primary numerical contract is bitwise equality for routing top-k, routing weights and FFN output, same captured activation and full native microbatch. A mismatch is FAIL/diagnostic; no post-hoc tolerance. Reader checks input file shape, dtype, strides, duplication and completeness. Full-model OFF/ON is already qualified only at two prototype positions and is not extrapolated to all capture points.

Resource envelope: fresh cgroup memory.max18 GiB/swap.max0, RSS<=17 GiB, GPU<=7000 MiB, MemAvailable>=6 GiB, CPU/GPU/NVMe<=95/80/70 C; timeout 900 s per target capture and 180 s per layer reference. A failed run remains failed with its own identity. Raw roots are created exclusively and never overwritten. No global cache manipulation. Reporting will enumerate actual layers, phases, shapes, rows and unavailable churn/lifetime witness classes; a target failure precludes promoting its partial rows.
