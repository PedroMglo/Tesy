# C125b — model-free authoritative component read discriminator

**Question.** C123's warm153 decode trace measured 10.646 s of readiness wait and 10.013 s of direct-read interval union, while accepted queue delay totaled only 0.047 s. 77.4% of the 46×36 decode layer invocations had zero or one expert load. In the current source, each loaded expert's three 4,406,400-byte weight components are read serially in one worker before the tensor sets. Test whether reading those already selected components independently reduces the exact-offset read-only elapsed enough to justify a bounded backend prototype. Alternative: direct NVMe contention or overhead removes the apparent opportunity.

**Preserved failure.** The first C125 freeze, source `2cee1acb788676cb0660c075cf8526cc52042fb7`, failed before protocol publication because `model_path` was a `Path` in JSON. `results/c125-component-io-probe-20260929T1554Z/decision-effective.json` records `FAIL_HARNESS_FREEZE_PREMODEL_JSON_PATH`. No model was loaded, and no four-arm read screen ran. C125b is a new identity after the type correction in source `4b9b650ff6ba4f809e74fad4b48aa244fb782057`.

**Frozen input/contract.** C123 trace SHA256 `c47d8fcd3056d41fd448c2a45d619153418dad89567bfa5ab4dd2aa5a8b86f3a`; C7 native GGUF inventory SHA256 `2c8ca725f50000bf3177712cfa30d29a809f77f25826b425ea67d8fcbffd6d82`; model target SHA from previously verified provenance `582bd40f6886200101f4c4ed9f25f3fe80cc14c86e9e2b37746cd8904a0c622d`, with stat rechecked before measurement. The fixed trace has 1509 decode loads and 1012 nonempty `(call, layer)` groups, 19,947,772,800 logical component bytes per arm. Tensor offsets are derived from the GGUF metadata, with bounds and shape/type checks. The unit reads those bytes with O_DIRECT and checks every read length; it does not allocate model tensors, execute routing or perform compute.

**Design and prospective decision.** Four arms ABBA: serial (four workers, three components serial per expert), parallel (twelve workers, components concurrent), parallel, serial. The order and group barriers are identical; no global cache flush. Each arm has a 180 s timeout, an E18/zero-swap scope, live resource/power checks before, during and after, and a small JSON receipt. Primary is paired read-only elapsed, with both parallel arms faster and median paired gain≥15% required to invest in one bounded backend prototype. A weaker result is NO_GO for this component-read intervention in this trace, not a universal I/O bound. Even a positive microprobe is **not** a server speedup or a same-profile numeric PASS; those require a new backend build, canary and uninstrumented A/B. Physical bytes, controller exclusivity and production read overlap are not identified by this microprobe.

**Admission and tests.** `budget-admission.json` uses the same post-C119 epoch, includes C121/C122/C123/C124 live receipts plus the conservative unreceipted-live allowance, and reserves 1320 s for C125b and closure. At freeze, the physical remaining lower bound was 24,369.5 s and wall remaining 34,568.4 s. Two directed model-free tests passed for exact offsets/counts and aligned/short read behavior; one real 4.4 MB O_DIRECT expert-component read passed. Root `results/c125b-component-io-probe-20260929T1555Z/` is frozen but not measured until the separate measurement commit. No remote/default change.
