# C21 paired prefix latency: prospective protocol

- Objective: distinguish exact-prefix cache latency benefit from warm-server and run-order effects for the already observed C19 mechanism. Alternative: reuse of 510 IDs exists but server response time does not improve enough, or merely reflects uncontrolled thermal conditions.
- Base commit `12c8c1f`; measurement commit will be frozen after protocol/preflight compact commit. Source backend `1248fd8fa8cfebaece5ea992e4d951c1e18bb9d5`; 120B model SHA and exact metadata in C21 preflight. Evidence class is new paired physical measurement; C20 incomplete data is excluded from gains.
- Source feasibility: C19 cache ON observed 510/510 common IDs; C20 OFF second request took 93.931 s, but no paired ON existed. A meaningful saving is plausible and refutable. Cost: four fresh 120B server processes plus idle admissions. Numerical risk: same-profile output divergence or invalid reuse; either stops the unit.
- Frozen input, order, identity, masks and server config are in `results/c21-prefix-pairs-20260927T1927Z/protocol.json` and per-run protocols. Only second-request cache flag changes. Completion-fenced second request is primary; first cold request and all output/resource/cache checks are gates.
- The C20 start-band rule was too strict for natural cooldown. C21 requires a continuous 300 s idle window with CPU/GPU/NVMe ≤50/50/45 C, and matching to first arm within ±5/5/3 C, all declared before C21 model outputs. Absolute CPU100/GPU80/NVMe70 and E18 zero-swap guards stay fixed. Do not heat the machine to satisfy matching.
- Screen: two alternating OFF→ON and ON→OFF pairs, median second-request gain ≥20%, each >0, median first-cold gain ≥−5%; results descriptive. Three fresh confirmation pairs only if screening passes. No old time enters a gain.
- Tests: 39 focused model-free PASS including old/new thermal-start discrimination. C21 preflight PASS; physical runs NOT_RUN at protocol freeze.
- Failure policy: no retry/relabel on numerical, resource or evidence failure. Incomplete thermal admission becomes `THERMAL_PREFLIGHT_BLOCKED` without model timing claim; a new identity is required for a changed policy.
- Limits: this is a synthetic 512+128 prefix screen, not 60-minute session, quality, p95, full-logit or M4 evidence. C15 remains SOURCE_ONLY. Next gate is C21 four arms, then confirmation only on screen GO.
