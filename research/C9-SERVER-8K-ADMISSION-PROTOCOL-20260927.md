# C9 8K server admission protocol

- Objective/base: test whether the original P8 backend with native preload ON loads one 8192-token full-SWA server context under E18. Base is local C8 long evidence commit `8fa71b7`, backend `1248fd8fa8cfebaece5ea992e4d951c1e18bb9d5`, existing 120B GGUF SHA256 `582bd40f6886200101f4c4ed9f25f3fe80cc14c86e9e2b37746cd8904a0c622d`. This is a new server profile, not a continuation of probe timing.
- Hypothesis/alternative: the context admits with sufficient E18 reservation for a separately gated forward; alternatively KV/server/workspace exhausts the reservation. Exact prefix reuse is a later hypothesis and cannot be inferred from init-only.
- Frozen profile: `results/c9-20260927T1441Z/protocol.json` records the full server argv, binary/library hashes, model stat, backend tree and limits. P8 ngl8, ub32, slots32, native preload ON, SWA full, KV F16/offloaded/unified, one sequence, O_DIRECT and no mmap. The usage contract fixes one 8K session, cold 512/2048, exact prefixes 2048/4096 plus 128 incremental tokens, medium reasoning and explicit output reserve before response observation.
- Gate/decision: a single init-only systemd user scope, MemoryMax 18 GiB, MemorySwapMax 0, 120 s timeout. Require actual mapped backend libraries, PID/start ticks/cgroup identity, raw hashes, continuous samples and terminal endpoint. Admission reservation: GPU total ≤6500 MiB, cgroup ≤16.5 GiB, RSS ≤16 GiB, MemAvailable ≥6 GiB, swap zero, CPU/GPU/NVMe ≤95/80/70 C. Any violation or missing evidence is CAPACITY_NOT_ADMITTED; no automatic retry.
- Evidence before execution: C7 GGUF inventory gives 29 CPU and 7 GPU expert pools, 12,267,417,600 and 2,961,100,800 B. C8 P8 4K probe max was GPU 3900 MiB, RSS 14,963,195,904 B and cgroup 14,781,255,680 B. An 8K server and first-forward workspace were not measured. Model-free gate suite: 67 PASS, including missing receipt/library/RSS/OOM/timestamp mutants. Historical C6 library/resource receipts remain incomplete.
- Tests/next: init-only pending at freeze; forward, API timing, prefix reuse, 12-task utility, 8K boundary and sustained regime NOT_RUN. If init passes, freeze a minimum-forward unit before any longer workload. No usual server/default change or remote publication.
