# C47 CPU parked-pair skip: feasibility and numeric protocol

- Objective: test whether omitting parked CPU expert dots preserves P12's exact routed computation in the frozen 189+32 numeric boundary before any timing promotion.
- Base: investigation `38348e6` (C46 close); backend C46 `005e8ff8dd264a2fdecd6dd99e42580d8d2674dc`; isolated C47 source `6a2c6c1f0c1032b5567d2a8463eb9bce85df94e8`. Original backend `1248fd8fa8cfebaece5ea992e4d951c1e18bb9d5` remains a separate control.
- Evidence class: source/static feasibility plus model-free operator tests. C46 observed 10.057% active pair slots and 69.911% tagged MMID time without tagged I/O overlap relative to C43 control prefill. The loose ideal removable fraction is bounded by these measurements only under the unproved assumption that CPU dot cost scales with skipped pairs and lies on the critical path; overhead and unchanged nodes reduce it.
- Mechanism: a `-1` sentinel marks a parked pair only when its streamed weight buffer belongs to a CPU backend and the C47 environment flag is set. In the normal CPU `MUL_MAT_ID` kernel, that pair's activation conversion and dot are skipped, and its complete output column is written as `+0` before the thread barrier. Routing IDs/weights, expert bytes, biases, graph shape, wave order and final mask are unchanged. GPU/other backends continue the old path. Frozen `--no-repack` prevents the separate repack kernel from seeing the sentinel.
- Alternative: parked outputs may influence later arithmetic, the buffer/device test may be wrong, or active rows may change bits through scheduling. A model-free F32/F16 test does not prove MXFP4 full-model correctness.
- Numeric gate: same C47 binary with flag OFF, ON, and ON in a fresh process; one 189-ID external prefill call with internal ub32 and final-only mask, then 32 teacher-forced calls. Compare all six core stages over 250 numeric states and five complete 201088-F32 logits bitwise, with two explicit masked states. Verify bytes/lifetime witnesses and same environment except flag. Stop on first mismatch/resource/evidence failure. Run 36 C47 canonical layer loads in a new frozen unit only if this passes. Timing is not promotable yet.
- Resources: E18, swap zero, RSS 16 GiB reservation, cgroup 16.5 GiB, GPU total 6500 MiB reservation/7000 MiB absolute, MemAvailable 6 GiB, CPU 95 °C warning/100 °C stop, GPU 80 °C and NVMe 70 °C stop. One 300 s idle admission before each arm, with comparable starting temperature. Timeouts 600 s per capture; no retry.
- Tests/NOT_RUN: initial generic-MMID insertion and incomplete-buffer dereference build failures corrected before model; final build/help and F32/F16 operator test passed. Existing 41 gate tests passed. Historical valid C7b capture passes the C47 schema parser; ON-without-sentinel mutant fails. Full-model OFF/ON, same-pin canonical reference, timing, production serving and M4 are NOT_RUN at freeze.
- Decision: if boundary fails, preserve FAIL and do not time. If it passes, run same-pin canonical references; only then screen full-model timing in a new unit with frozen pairs and thresholds.
