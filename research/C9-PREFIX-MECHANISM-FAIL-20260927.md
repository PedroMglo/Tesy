# C9 prefix mechanism thermal failure

- Objective/base: observe exact token-prefix reuse in the original 8K P8 native preload ON server under E18. Measurement commit `a65e721a3fca2bd344bc4b0ee44aca5ed851a3b8`, clean before launch; input/protocol02 and ON→OFF order were frozen. The original input/protocol01 was abandoned before model execution after a model-free estimate showed it would likely miss the token-count range.
- Evidence class: one physical target ON arm launched with its own systemd user scope. The incorporated model tokenizer produced 513 and 641 prompt IDs, with 510 common IDs, and saved their bytes/hash before either output. Mapped backend libraries, process/cgroup identity and samples were collected. No request finished.
- Failure observed: CPU Tctl reached 95.125 C at 75.16 s during the first 513-ID prefill, exceeding the frozen 95 C guard. The watchdog stopped the server; process returncode was −9, scope elapsed 80.624 s, 71 samples, and the pending HTTP request then disconnected. The disconnect is secondary to the thermal stop. The OFF arm was not started and no retry occurred. No `cache_n`, paired timing or functional response exists.
- Other resources: sampled RSS maximum 15,164,157,952 B, cgroup peak 14,985,920,512 B, GPU total 3936 MiB, GPU 61 C, NVMe 44.85 C. Swap and cgroup cap/OOM events remained zero; no NVIDIA/Xid/OOM kernel event was found in the queried interval. The own server stopped, port 18367 closed and no GPU compute process remained.
- Decision: `FAIL_RESOURCES_OR_EVIDENCE` for this unit. Earlier 8K init and 78-token forward admissions remain scoped observations; this 513-token workload is not qualified. A source/thermal diagnosis and a new profile/campaign with new preflight are required before another physical serving attempt. Raising the 95 C guard or replaying this allocation is not justified. The independent confirmed 496+32 preload probe result remains separate. The usual service/default is unchanged.
- Alternative/next: a CPU batch-thread change is a candidate mitigation but may slow prefill and may form a distinct numerical profile; estimate and freeze before use. Independently, model-free analysis of C8 wave/placement traces can proceed without serving the model. The 2048/4096 session prefixes, 7936+256 boundary, 12-task quality and sustained >=60 min/20 requests are NOT_RUN.
